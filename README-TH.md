# ชุดไฟล์สร้าง APK แอป "บันทึกโพย"

ไฟล์ zip นี้รวมทุกอย่างที่ต้องใช้คู่กับคำสั่งสำหรับ GitHub Copilot

## ในชุดนี้มีอะไร
| ไฟล์/โฟลเดอร์ | หน้าที่ |
| --- | --- |
| `COPILOT_PROMPT.md` | คำสั่งที่ส่งให้ Copilot |
| `www/` | ตัวแอป (index.html, ไอคอน, manifest) |
| `package.json`, `capacitor.config.json` | ตั้งค่า Capacitor สำหรับห่อเป็น Android |
| `github-workflows/build-apk.yml` | ขั้นตอนสร้าง APK อัตโนมัติ (Copilot จะย้ายไป `.github/workflows/`) |
| `github-config/copilot-instructions.md` | กติกาถาวรของโปรเจกต์ (Copilot จะย้ายไป `.github/`) |
| `tests/core.test.js` | เทสต์ตรรกะ 32 ข้อ |
| `docs/SPEC.md` | ข้อกำหนดแอปรุ่นแรก |
| `docs/TEST-CHECKLIST.md` | รายการทดสอบบนโทรศัพท์จริง |

## ข้อควรรู้ก่อนเริ่ม (ตามจริง)
- ผู้ช่วยที่เขียนชุดนี้ **ไม่ได้รัน** workflow สร้าง APK เพราะไม่มีอินเทอร์เน็ตในเครื่องทดสอบ จึงยังไม่รับรองว่า build ผ่านตั้งแต่ครั้งแรก นี่คือเหตุผลที่คำสั่งให้ Copilot แก้และรันซ้ำจนสำเร็จ
- ตรรกะแอป (เทสต์ 32 ข้อ) และหน้าจอในเบราว์เซอร์จำลองผ่านแล้ว ส่วนการส่งออกไฟล์สำรองในแอป Android เขียนไว้แต่ยังไม่ได้ทดสอบบนเครื่องจริง
- Copilot cloud agent (แบบรับงานแล้วเปิด Pull Request เอง) ต้องใช้แผน Copilot Pro ราคาประมาณ 10 ดอลลาร์สหรัฐต่อเดือน แผน Free ไม่รวมฟีเจอร์นี้ (ตรวจแผนปัจจุบันที่หน้าราคาของ GitHub อีกครั้งก่อนจ่ายเงิน)
- ถ้าไม่อยากจ่าย: ไฟล์ workflow ในชุดนี้สร้าง APK ได้เองโดยไม่ต้องมี Copilot ข้ามไปที่ "ทางเลือกไม่ใช้ Copilot" ด้านล่าง

## ขั้นตอนบนมือถือ (ทางหลัก ใช้ Copilot)
1. ในโทรศัพท์ เปิดแอป Files แตกไฟล์ zip นี้ (กดค้างที่ไฟล์ แล้วเลือก แตกไฟล์/Extract)
2. เปิด github.com ในเบราว์เซอร์ สมัครหรือเข้าสู่ระบบ แล้วกด **New repository** ตั้งชื่อ `poy` เลือก **Public** หรือ Private ตามที่ต้องการ แล้วกด **Create repository**
3. กด **uploading an existing file** แล้วเลือกไฟล์และโฟลเดอร์ทั้งหมดที่แตกออกมา (ยกเว้นไฟล์ zip) จากนั้นกด **Commit changes**
   - ถ้ามือถือเลือกโฟลเดอร์ทั้งก้อนไม่ได้ ให้อัปโหลดทีละโฟลเดอร์ หรือเปิดเว็บแบบ "เวอร์ชันเดสก์ท็อป" ในเมนูของเบราว์เซอร์
4. ไปที่แท็บ **Issues** กด **New issue** ตั้งชื่อว่า `สร้าง APK` แล้วเปิดไฟล์ `COPILOT_PROMPT.md` นำข้อความระหว่างเส้น ===== ไปวางในช่องรายละเอียด แล้วกด **Create**
   - ขั้นตอนนี้คือ "คัดลอกข้อความไปวาง" ไม่ใช่การแก้โค้ด
5. ในหน้า issue ที่เพิ่งสร้าง แตะ **Assignees** แล้วเลือก **Copilot**
6. รอ Copilot เปิด Pull Request (ใช้เวลาหลายนาที) ดูได้ที่แท็บ **Pull requests**
7. ถ้ามีปุ่ม **Approve and run workflows** ให้กดอนุมัติ (บางกรณี GitHub ต้องการให้เจ้าของที่เก็บอนุมัติก่อนรัน)
8. เมื่อ workflow ขึ้นเครื่องหมายถูกสีเขียว ให้กด **Merge pull request**
9. ไปที่ **Releases** (ขวามือหรือเมนูของที่เก็บ) เลือกรุ่นล่าสุด แล้วแตะไฟล์ `poy-debug.apk` เพื่อดาวน์โหลด
10. เปิดไฟล์ APK ในโทรศัพท์ ถ้าระบบถามให้กด **อนุญาตการติดตั้งจากแหล่งนี้** แล้วกด **ติดตั้ง**

## ทางเลือกไม่ใช้ Copilot
1. ทำขั้นตอน 1–3 ด้านบน
2. สร้างไฟล์ workflow ให้อยู่ที่ `.github/workflows/build-apk.yml` โดยกด **Add file → Create new file** พิมพ์ชื่อไฟล์เป็น `.github/workflows/build-apk.yml` (พิมพ์เครื่องหมาย / เพื่อสร้างโฟลเดอร์) และวางเนื้อหาจาก `github-workflows/build-apk.yml` (ขั้นตอนนี้ต้องวางข้อความเอง)
3. ไปที่แท็บ **Actions** เลือก **Build APK** แล้วกด **Run workflow**
4. เมื่อสำเร็จ ดาวน์โหลด APK จาก **Releases** เหมือนขั้นตอน 9–10

## ถ้า build ล้มเหลว
เปิดแท็บ **Actions** แตะการรันที่ขึ้นสีแดง แล้วส่งชื่อขั้นตอนที่ล้มเหลวกลับมา หรือคอมเมนต์ใน Pull Request ว่า `@copilot แก้ build ที่ล้มเหลว` ให้ Copilot แก้ต่อ

## ความปลอดภัยของข้อมูล
- ข้อมูลโพยอยู่ในเครื่องเท่านั้น แอปไม่ส่งข้อมูลขึ้นคลาวด์ ที่เก็บ GitHub เก็บเฉพาะโค้ดแอป
- APK นี้เป็นรุ่น debug ใช้ทดสอบ ไม่ใช่รุ่นสำหรับ Google Play ถ้าถอนการติดตั้งแอป ข้อมูลในแอปจะหาย ต้องสำรองไฟล์ JSON ไว้ก่อนเสมอ
